Competitive Programming — repository overview

This repository contains competitive programming solutions organized by year, user, and contest. Use this README as a quick map — open folders for detail.

Top-level folders

- .cph: Problem metadata (.prob) used by some tooling.
- .vscode: Editor/IDE settings for this repo.
- 2024: Problems and solutions from 2024 (many .INP and .cpp files).
- 2025: Problems and solutions from 2025 (pre11, PRE-11, contests, etc.).
- binary: Compiled binaries and test executables.
- chatnhiphansongsong: (personal project or contest; inspect folder for details).
- dutuyen: Solutions grouped by author/team member (subfolders: DUNG, MINH, NGUYET, algorithms like dijkstra/dsu/tarjan).
- hanhvanpham: Solutions by user "hanhvanpham" (contest folders and tasks).
- KIEN: Kien's contest folders (contest1..contest8) — organized by contest number.
- mttn: (author or topic-specific folder; inspect contents).
- Priority_Queue: Algorithm category or examples related to priority queues.
- tabi: (topic or author-specific; inspect inside).
- temp: Temporary files, experiments, and scratch code.
- test, test1, test2, test3: Various test/problem sets and sandbox code.
- tons: Miscellaneous collection (inspect to see contents).
- traihe2026: Summer 2026 contest/training problems organized by day.
- week_7, week_8: Weekly contest/problem sets.

How to use

- Open the folder that matches the year, author, or contest name.
- Many folders have subfolders named by contest or day (e.g., KIEN/contest8, traihe2026/day3).
- Look for files with .cpp/.c for solutions, .INP for sample inputs, and .prob for metadata.
